# Sons de Mikky

Mikky joue les fichiers `.mp3` de ce dossier (`app/lib/sound/sound_board.dart` dit lequel pour quoi). Un fichier absent : Mikky reste silencieux, rien ne casse.

**Les fichiers ne sont pas dans git** : le dépôt est public, et les sons actuels (thème « PlayStation Portable », Sony, plus `retroachievements.mp3`) ne sont pas à nous. Les garder en local, ou les remplacer par des sons libres (CC0) ou faits pour Mikky avant toute distribution.

Fichiers attendus : `back`, `folder_close`, `folder_open`, `launch`, `navigate`, `retroachievements`, `select` (`.mp3`).
