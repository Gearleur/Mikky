# Logos des outils

Repris du dépôt de Paperclip (MIT, https://github.com/paperclipai/paperclip) :

- `claude-color.svg`, `openai*.svg`, `gemini-color.svg`, `pi*.svg` : icônes de Lobe (https://github.com/lobehub/lobe-icons, commit `a94750e3f5f8fc33757b839d85030e742284e43a`), licence MIT (`LICENSE-lobe-icons`).
- `opencode-logo-*.svg`, `openclaw.svg` : fichiers du dépôt de Paperclip (`ui/public/brands/`, `doc/assets/logos/`), licence MIT (`LICENSE-paperclip`).

Les noms et les marques appartiennent à leurs propriétaires ; Mikky ne les montre que pour dire quel outil fait tourner une session.
